# The Deafening Colors

Website for the band, rebuilt as a static site in September 2026 after a decade on Wix. Hosted on Netlify.

- `data.mjs` holds every piece of content (releases, shows, press, videos, bio).
- `news/*.md` is the blog archive.
- `node build.mjs` writes the site to `dist/`.
- `STATUS.md` says where things stand and how to deploy.

Bandcamp is the home for the music: https://thedeafeningcolors.bandcamp.com
